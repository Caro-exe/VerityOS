# VerityOS
Introducing VerityOS! Inspired both off of the operating system theme, halloween and the popular minecraft movie,
I've made this little project. I'm planning on adding more in the future of course! But I have this for now!
I made sure to use eclectic styling to give this OS a sort of old vibe that matches with the themes of old internet horror game...
As a warning, it is based off of a horror mod! It's all pretend, may be mildy ominous... (Happy halloween)!
# Features: 
In this OS you are welcomed by a welcome window, it will tell you to open the Q & A section, 
There will be a few questions to pick from there, showing off my newly developed knowledge from the coding jam
There is also an installer, in which you can "install" verity!
Talk to him! 
Enjoy! 
# Reflection
Over the course of this project I learned more about HTML, Javascript, and CSS, and had to deal with a large amount of bug fixes. I can now confidently use classes, arrays, inputs, and understand how to seamlessly connect all of my languages together, making the project come to life. This project originally had a different theme, but after first doing the tutorial for Personal Websites, I decided it would be more engaging for me and for my friends to see something different... something fun! We agreed that I should make something about Verity because we love referencing it, and I'm pretty sure a lot of people in hackclub know who they are too! :D
